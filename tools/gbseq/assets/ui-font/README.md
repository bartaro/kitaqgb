# Noto Sans CJK JP Regular

GBSEQ uses this unmodified pan-CJK font for GUI characters missing in the primary font, including Hangul and Chinese. It is independent of the title font embedded in Game Boy exports. Copyright and the SIL Open Font License 1.1 are in [OFL.txt](OFL.txt).

Source: [notofonts/noto-cjk, pinned original OTF](https://raw.githubusercontent.com/notofonts/noto-cjk/f8d157532fbfaeda587e826d4cd5b21a49186f7c/Sans/OTF/Japanese/NotoSansCJKjp-Regular.otf).
