# LINK16_PLAYER_ROM_V3 / SRAM不要のミュージックプレイヤーROM

GBSEQの`export-player-roms`と「再生専用ROM（SRAM不要・台別）」が出力する形式です。
従来の同一ROM＋128KB SRAM方式とは別の実行形式です。

## パッケージ

`LINK16_PLAYER_<曲ID>`に`manifest.json`、日英手順書と1/2/4本のROMを作成します。
各ROMは524288バイト、MBC5（ヘッダー0147=19）、ROMサイズ0148=04、RAMサイズ0149=00。
ヘッダー0143=80（GB/GBC両対応）。GBは従来のモノクロ表示、GBCは専用配色で表示します。
GBCでは4CHメーターとCH名を青・橙・緑・紫に色分けし、曲名と操作文字は読みやすい濃色で表示します。
パレットと属性は起動時に設定し、演奏・同期処理には追加しません。
バッテリーSRAM、SAV、SRMは使いません。各ROMの担当Playerは固定で、
2台ならP1.gb/P2.gb、4台ならさらにP3.gb/P4.gbを使用します。通信役は固定しません。
既存パッケージへの上書きは拒否します。

## ROM内の配置

| ファイル位置 | 長さ | 内容 |
|---|---:|---|
| 00000..1FFFF | 128KB | 独立した再生用テンプレートのコード・フォント |
| 20000 | 16 | manifest |
| 20010 | 1280 | 上端の曲名画像（20×4タイル、行優先・GB 2bpp） |
| 24000 | 32768 | このPlayerだけの曲・音色・波形 |
| 2C000 | ステップ数×16 | このPlayerの発音行。1バンク1024行、最大4バンク |
| 発音行の後..7FFFF | 残り | FFパディング。他Playerの曲データは含まない |

manifestは`L16P`、version=3、Player数（1/2/4）、モード（0=local/1=cable/2=DMG07）、
0始まりの担当Player、8バイトの曲IDで構成します。曲IDは`L16P`＋共通のFNV-1a32値です。
標準GBヘッダーのタイトルには曲IDと担当番号を含め、両チェックサムを再計算します。

32768バイトの曲領域は、既存`L16X` V4の1Player領域と同じデータ配置です。
ただしSRAMへ展開せず、ROMバンク9/10から直接参照します。先頭ヘッダーの担当番号と
manifestが一致しない場合は起動を拒否します。32752..32759にはこの形式の曲IDを置き、
V4チェックサムも更新します。V4の配置の再利用はSRAMの使用を意味しません。

発音行のバイト0..6は同じステップのV4行、7は発音区間マスク、8は発音開始マスク（bit0..3=CH1..4）。
9..12は順にNR12、NR22、NR32、NR42、13はNR10、14..15は予約（0）です。
発音開始時だけトリガーするため、長音の途中でスイープやエンベロープが初期化されません。
CH4のノイズ値FFも、休符とは別に扱えます。編集ROM・SAVのV4データ形式は変更しません。
最大4096ステップ、16波形スロット、最大64ユーザー波形。GUIのミュート／ソロは試聴専用です。

## 実行

担当する4CHだけをROMから読み、既存LINK16と同じtransportを使用して同期します。
編集・セーブ転送パケットは無効化します。起動は常にSOLO。STARTで試聴／停止します。
停止中、SOLOまたはMASTERでBを押すとループのON/OFFを切り替えます。PEERはMASTERに従います。
SRAMは使わないため、電源を入れ直すと出力時の曲設定に戻ります。
停止中にSELECTで通信メニュー、A=MASTER、B=PEER、SELECT=SOLO。同期時の再生／停止はMASTERのSTARTです。
4人用はMASTERを物理ポート1に、PEERを残りのポートへつなぎます（担当パート番号とは無関係）。
曲名は出力時に日本語対応フォントで中央揃えの2行に描画し、収まらない場合は省略記号を表示します。
中央のメーターは各CHの発音・ルーティング・設定音量を示す目安で、周波数分析器ではありません。
通信は音声を混合しません。同じV3出力セットで全台を揃えてください。
検証は実ROMを実行し、SRAMが0バイトでも各Playerの音程・音量・波形と終端を確認します。
エミュレーターの結果は実機確認とは区別します。
