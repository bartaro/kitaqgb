LINK16 / 実機用SDパッケージ（SRM）の取り込み

P1_SD_ROOT の中身だけを1台目のSDカード直下へ、P2_SD_ROOT の中身だけを
2台目へコピーしてください。4台構成も同様です。P1_SD_ROOTフォルダー自体を
置いたり、全プレイヤーのSAVEを1枚に混ぜたりしないでください。
EDGBフォルダーはSAVEを追加するだけです。OSやREGISTRYは配布・変更しません。

ROM: SD直下の Lxxxxxx1.gb など
SRM: SD直下の EDGB/SAVE/Lxxxxxx1.srm など
ROMとSRMの名前（拡張子以外）は完全に一致しています。
曲のデータが変わると別名になります。ROMの内部タイトルではなくファイル名を
使ってください。ROMのバイト列は、選択した元ROMと同じです。

重要: SDカード上のファイルとカートリッジ内のSRAMは別物です。
同じROMをSTARTで再開するだけでは、SDに置いた新しいSRMが取り込まれない
OSがあります。また、前回のSRAMが後からSDのファイルを上書きする場合があります。

安全な手順:
1. 既存のSDとセーブをPCへバックアップしてください。
2. 前回LINK16を使っていた場合は、まず別の保存データ不要のソフトを読み込み、
   古いLINK16のSRAMの書き戻しを済ませてから電源を切ってください。
3. 電源OFFで、このパッケージの対応するP番号の中身をSD直下へ追加します。
4. カートリッジのメニューで新しい名前のROMを選んで読み込みます。
   前回のゲームをSTARTで再開するだけでは不十分です。
5. それでも曲が出ない場合、OSに Select Only / Copy File to SRAM があるなら:
   ROMをSelect Onlyで選択 → EDGB/SAVEにある同名SRMを選択 →
   Copy File to SRAM → STARTで選択済みROMを実行。
   Copy SRAM to File は逆方向で、取り込みたいデータを上書きするので選ばないでください。
6. ケーブル版はP1でA(MASTER)、P2でB(PEER)を選びます。
   Pure Techno Pop R2なら48小節、768ステップ、BPM120、再生区間P001-P048が目印です。
   役割を選んだ後の初期読み込みは遅く、今回のROMではソフト検証で
   P1約18秒、P2約9秒相当かかりました。初期化が終わるまで待ってください。
   SAVED PATTERN LOADED が出ればSRAMを読み込めています。

SRMはヘッダーなしの131072バイトです。通常のSAVと同じ生SRAMデータで、
バイトスワップ、パディング、圧縮、32KiBへの切り詰めは不要です。
LINK16はMBC5＋128KiB RAMが必要です。カートリッジは機種やOSが異なるので、
32KiBまでの機種や、MBC5の16 RAMバンクを扱えない機種では保証できません。
ROMのRAM容量表示だけを32KiBに偽装すると曲や他プレイヤーのデータを壊す恐れがあります。
別機種用ファームウェアの導入は、この修正には含めません。

実機確認がまだの配布物です。失敗した場合は、カートリッジのOS/基板情報と
SDから読み戻したSRMを保存してください。曲が正しく読み込めるか、
実機での保存・再起動・同期演奏は利用者による確認が必要です。
